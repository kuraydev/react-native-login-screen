# Contributing

Thanks for taking the time to contribute! This library is a pure JS/TS React
Native component — there is no native code to build.

## Development setup

```bash
git clone https://github.com/kuraydev/react-native-login-screen.git
cd react-native-login-screen
npm install --legacy-peer-deps
```

The source lives in `src/`. The published build output (`lib/`) is generated by
[`react-native-builder-bob`](https://github.com/callstack/react-native-builder-bob)
and is git-ignored.

## Useful scripts

| Script                  | What it does                                        |
| ----------------------- | --------------------------------------------------- |
| `npm run lint`          | ESLint (flat config) over `src`                     |
| `npm run typecheck`     | `tsc --noEmit`                                       |
| `npm test`              | Jest + `@testing-library/react-native`              |
| `npm run test:coverage` | Jest with coverage                                  |
| `npm run build`         | Build commonjs / module / typescript targets        |
| `npm run format`        | Prettier over `src`                                  |

Please make sure `lint`, `typecheck`, `test` and `build` all pass before opening
a pull request. CI runs the same checks on Node 18, 20 and 22.

## Commit messages

This project uses [Conventional Commits](https://www.conventionalcommits.org/)
(enforced by commitlint) so that `semantic-release` can derive versions and
changelog entries. Examples:

- `fix: guard LayoutAnimation on Android`
- `feat: add accessibilityLabel to social buttons`
- `docs: correct the props table`

## Backward compatibility

This is a published, widely-used library. **Do not rename or remove public props,
and do not change runtime default values** without flagging it as a breaking change
in the PR description and the changelog. Documentation should be fixed to match the
code, not the other way around — unless it's a genuine bug fix.

## Adding tests

New behavior should come with tests under `src/__tests__`. Prefer
`@testing-library/react-native` queries (`getByText`, `getByLabelText`,
`getByPlaceholderText`) and `fireEvent` over snapshot tests.
